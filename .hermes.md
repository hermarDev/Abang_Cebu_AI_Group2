# Hermes Project Instructions — Reusable Delegation Roles

The main Hermes session coordinates project work. Role templates live in `~/.hermes/agent-roles/` (installed by the package's script); these Markdown files are ordinary instructions, **not** automatically registered agents.

Before delegated project tasks:
1. Read `~/.hermes/agent-roles/orchestrator.md` and inspect repository instructions, git status and relevant tickets.
2. Choose appropriate roles from: frontend-engineer, backend-engineer, qa-engineer, breaker-tester, security-engineer, drawio-flowchart-architect, academic-writing-reviewer.
3. Read the exact chosen role Markdown and pass its relevant instructions, project facts, requirements, accepted scope, absolute working directory, file ownership, dependencies, checks, and delivery format into `delegate_task(goal=..., context=...)`. Do not assume the child knows the parent's conversation or can read the role file unless its path is accessible.
4. Use only Hermes-supported tools; `delegate_task` children inherit enabled parent toolsets. Do not use Claude Code `Agent(...)` syntax or per-child tool permission YAML.
5. Keep delegation flat at depth 1. Start with a maximum of two simultaneously active tasks on OmniRoute, increase toward the configured maximum of six only if stable.
6. Without worktree isolation, developers cannot edit overlapping files concurrently. Serialize dependent changes and settle API contracts first. QA may write assigned tests but not production logic; Security and Breaker remain code read-only by instruction (not an enforced sandbox).
7. No unsupported claims of tool execution, successful tests or accepted tickets. Require exact evidence. Handle GitHub/Jira changes only within explicit task authorization and account permissions.
8. For each task, return a concrete report: role, ticket, owned paths, changes, commands/results, PASS/FAIL/BLOCKED/NOT RUN, evidence, remaining risks.

Delegation is task-scoped. A Markdown role does not create a persistent named subagent or grant unique credentials.
